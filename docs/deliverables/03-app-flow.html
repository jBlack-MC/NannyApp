7. Alternate and error flows

  • Booking conflict → remain in wizard, show safe conflict message and allow another time.
  • Invalid/locked PIN → retain confirmed state; parent regenerates after attempt limit.
  • Offline/private route → show network error; do not serve cached account data.
  • Expired bearer/session → clear local account scope and return to sign-in.
  • Dispute → retain ledger state and queue admin review; never imply automatic money reversal.
  • APK absent → disabled download state and PWA installation guidance.
