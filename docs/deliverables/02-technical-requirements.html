3. Performance and capacity

  • Target p95 authenticated page/API response under 800 ms at pilot load, excluding email delivery and large media transfer.
  • Database-backed lists must paginate before any table can exceed 500 rows; message thread currently caps at 500 and should add cursor pagination before scale.
  • Uploads default to 100 MiB aggregate and 20 MiB free-disk reserve; configure production values from measured EBS use.
  • Workers process bounded batches (up to 100 jobs) and run every minute; alert when oldest due job exceeds five minutes.
  • Measure CPU, memory, DB locks, disk, request latency and error rate before resizing or separating RDS/S3.

4. Security requirements

Identity

Bcrypt passwords, verified active accounts, 90-day bearer expiry, credential rotation, rate limiting and admin exclusion from Android.

Authorization

Role and ownership checks at every controller; parent-only PIN visibility; private media streamed or short-lived signed after authorization.

Application

CSRF for web mutations, strict JSON validation, PDO prepared statements, output escaping, safe 4xx errors and no public worker/migration endpoints.

Infrastructure

HTTPS only, HSTS, secrets outside source, IMDSv2, encrypted disks/backups, DB unexposed and restricted SSH.

6. Quality and observability

  • PHP syntax, JavaScript syntax, migration, HTTP/auth/media, security, PWA, cache-isolation and APK-download tests must pass.
  • Android debug assembly, JVM tests and lint must pass; release must reject absent or non-HTTPS API URL.
  • Logs exclude authorization/cookies, request bodies and account-link query strings.
  • Alert on repeated 5xx, worker failures, pending queues, low disk, DB failure, TLS failure and backup failure.
Known delivery limit: source checks are not production evidence. Live mail, AWS deployment, restore, signing and physical-device validation remain mandatory.
