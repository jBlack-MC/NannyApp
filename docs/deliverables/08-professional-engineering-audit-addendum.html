Updated evidence

The full disposable database/API regression suite now passes. It covers registration, duplicate-account conflicts, password hashing, mobile bearer login, session-version revocation, named demo-account password hashes, media authorization, web/API sessions, bookings, messages, uploads and notification flows.

The web application and Android API both load the shared database configuration and use the same database-backed account records. The Android client does not connect directly to the database; it calls the PHP API with a bearer token.
